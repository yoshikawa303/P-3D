### 2026-11-02 19:54 JST - Claude Code (Sonnet 5.5) - 種別: 作業結果 - デモ以外の人物分離精度・文字組先行分離の提案・アイデア（概算90分）
- 提案「文字組背景を先にレイヤー分離してから立体化」: 前回までに実装済み（`detectGraphicOverlay` → 文字除去画像で再分離 → 手前レイヤー＋人物＋補完背景の3層）。雑誌表紙では主要な文字を分離できているが、淡い／半透明の文字、人物下端に接する小さな文字は未分離（REPORT.md 残課題）。
- 計測: 正解付きデモ前景を別背景へ合成した「背景入替」5件・人物縮小4件を QC ハーネスへ追加。背景入替は IoU 0.936〜0.976、人物が小さいほど低下（60% 0.92、45% 0.87〜0.93、30% 0.89）。
- 実装（採用）: `zoomRefinePersonMask`（人物外接範囲を切出し拡大して再分離、失敗時は元マスク）。小さい人物で IoU +0.016 程度。通常サイズのデモ7件・雑誌表紙は完全不変（平均40.9）。
- 実装（不採用・撤回）: 局所色モデルによるマット補正。全ケースで悪化（swap_mint IoU 0.937→0.906）。
- 結論: 誤りの主因は解像度ではなく意味的な取り違え（足元の椅子、髪色に近い背景）で、256px級モデルの限界。実写の失敗例は未入手のため実写固有の失敗は未計測。
- 検証: QC ハーネス（実 MediaPipe モデル、デスクトップChrome系）、`web_regression_gate.py` PASS。iPhone Safari・Pages 未検証。
- 記録の扱い: 計測出力のうち著作権のある雑誌表紙由来の画像は commit せず削除（自分が生成した S3_final の2枚）。既存 T0〜T13 フォルダには雑誌表紙由来の画像が既に含まれる（別セッション作成。CLAUDE.md §3 の観点で要判断）。
