### 2026-11-03 12:30 JST - Claude Code (Sonnet 5.5) - 種別: 作業結果 - 文字分離の改善（概算90分）
- 原因: `detectGraphicOverlay` が3x3平坦成分のみを文字候補にするため、網点・色ムラのある文字と人物から離れた文字を取りこぼし、背景層に文字が残っていた。
