# 人物自動分離・2層化 画質ループ改善レポート（2026-10-31）

計測ハーネス: `scripts/qc/layer_quality.html`（`python3 scripts/qc/serve.py 8140` → `http://127.0.0.1:8140/scripts/qc/layer_quality.html?trial=<名前>&src=/index.html`）。
`index.html` の関数を抽出して実MediaPipeモデル（selfie_multiclass_256x256）で評価し、各試行の `result.json` と分離結果画像（入力／マスク／人物層／補完背景／人物5%ずらし合成）を `<試行名>/` へ保存する。

## 指標
- 正解あり（同梱の2層デモ＋手前文字を合成した画像。正解層は同梱の前景・背景PNG）: `iou`（人物マスクIoU）、`bgHolePSNR`（人物があった範囲の補完背景PSNR）、`ringPSNR`（人物輪郭の外側6px帯＝滲み・ハローの影響）、`shiftPSNR`（人物を5%ずらした合成の正解との一致）、`overlayIoU`（手前文字の検出IoU）、`score`（IoU 40%・補完 30%・ずらし合成 30%の100点換算）。
- 正解なし（雑誌表紙）: `fillSharpRatio`（補完領域/周囲のラプラシアン比。0に近いほどのっぺり）、`skinMissRatio`、`roughness`、`edgeAlign` など。
- 正解ありケース7件: 通常4（ヒロイン／都会キャミ／ミントポニテ／ネイビーピクシー）＋手前文字合成3（ヒロイン／都会キャミ／ネイビーピクシー）。

## 雑誌表紙（正解なし）での確認
- 最終 T9b: 人物マスクは右肩・腕まで含み、「加藤玲菜」「こんなすごいスタイル…」「毎日アツイゼ」など主要な文字が手前レイヤーとして分離され、人物を5%ずらしても文字は元位置のまま人物だけが奥で動く（著作権画像のため画像はリポジトリに含めない）。
- fillSharpRatio は 0.11〜0.55（T0は未計測）。補完は人物が動いた時に見える範囲のみで、のっぺり感は残る。

## 残課題（限界）
- 淡い・半透明の文字（例「見たことある？」の一部）や写真と同色の文字は検出できず、人物層側に残る。
- 人物右腕の縁にモデル由来のブロック状の凹凸が残る。
- 補完背景は近傍色＋質感移植の擬似補完で、生成AIによる意味的復元ではない。
- デスクトップChrome系ブラウザでの計測のみ。iPhone Safari実機は未検証。
