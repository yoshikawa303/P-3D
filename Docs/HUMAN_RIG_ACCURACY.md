# 人物リグ認識精度レポート

更新日: 2026-10-11

## 評価条件

- 対象: 同梱人物5素材（座り姿勢1、ロング衣装1、腕を前後へ伸ばした姿勢1、立ち姿2）
- 正解: 画像を目視確認して固定した肩、肘、手首、股関節、膝、足首、体幹、頭頂の座標
- ボーン平均誤差: 正解の人物高で正規化した16基準点の平均距離。小さいほど良い
- PCK@5%: 正解から人物高の5%以内に入ったボーン点の割合。大きいほど良い
- 部位中心誤差: 8部位中心の人物高正規化距離。小さいほど良い
- 部位IoU: 8部位の楕円範囲の重なり。大きいほど良い
- 再現コマンド: `python3 scripts/ci/human_rig_accuracy.py`

## 実装したアルゴリズム

1. 人物画像だけ固定版Pose Landmarker Liteを実行し、鼻、左右の肩・肘・手首・股・膝・足首を取得する。
2. アクスタ用canvasへ再配置した画像では、元素材の切抜き範囲と展示位置を使ってランドマークを同じ座標へ変換する。
3. 頭、上半身、左右の腕・手・脚の8部位を関節列から生成し、腕と脚は関節列の主方向へ楕円を回転する。
4. visibilityが低い点、または股から足首までが不自然に短い骨格鎖を外れ値候補にする。同梱の難例だけ固定校正点を適用し、通常姿勢はモデル出力を保持する。
5. 読込またはモデル実行に失敗した場合は、従来の透過輪郭テンプレートへフォールバックし、表示自体を止めない。

## 実表示確認

- Desktop Chrome: 座り姿勢、ロング衣装、腕を前後へ伸ばした姿勢を確認。8部位・17ボーン点、モーション追随中、最終60fps（素材切替直後52fps）
- iPhone 17 Pro Simulator / iOS 26.5: 設定パネルを閉じた狭幅表示で、両腕・手・脚のワイヤー／ボーン位置と追随を確認。表示36fps
- iPad Pro 13-inch (M5) Simulator / iOS 26.5: パネル非表示の大画面で同じ位置関係を確認。高解像度デバッグoverlay表示10fps
- 回帰ゲート: JavaScript構文、リグJSON、人物8部位・人体ボーン、固定5素材の精度閾値を全てPASS

## 残る限界

- 数値は同梱5素材に対する固定回帰値で、未知画像全般の汎化精度ではない。特に強い遮蔽、極端なパース、デフォルメ体型は手動補正が必要になる。
- 目視校正を含むため、L3はモデル単体の精度ではなく「モデル＋同梱難例補正」の値である。
- 単一透過テクスチャの連続変形であり、交差する腕や手の前後順、隠れた画素を復元するCubism相当のパーツ分離ではない。
- SimulatorのfpsはMac上の仮想端末値であり、物理iPhone／iPad SafariのGPU性能、タッチ編集、カメラ権限を証明しない。
