# P-3D

iPhoneのフロントカメラで閲覧者の顔位置を追跡し、2DポスターをWebGLで擬似立体表示する技術検証です。

- 公開版: <https://yoshikawa303.github.io/P-3D/>
- 初回表示では、完全オリジナルの背景と透過立ち絵を別テクスチャにした2層デモを自動表示します。右上の`愛でる`または設定内の9枚のサムネイルで、ゆるキャラ／美少女／イケメン／モフモフ動物を切り替えられます。
- 成人の美少女2体／イケメン2体に加え、背景除去済みのゆるキャラ／モフモフ動物を、共通ショーケース内の`動くアクスタ`として表示します。頭、胴体、髪・布／毛、小物・尻尾の4つの影響域を別々の減衰ばねで微動させ、強度とON／OFFを設定できます。
- 従来どおり自分の画像も端末から選択できます。選択画像、カメラフレーム、人物マスクはブラウザ内だけで処理します。
- `Depth多層3D`では、白が手前のDepth Mapと、白が対象の人物／物体マスクを任意入力できます。
- 選択画像に対する人物自動分離も端末内で実行し、画像を外部サーバーへアップロードしません。
- `トリックポータル3D`は、人物／物体を額縁より手前へ出し、背景の透視変形、額縁の疑似厚み、背後影でだまし絵のような奥行きを追加します。
- ホログラム、ポップ3D、前景微振動、Depth多層、トリックポータルは複数同時に適用でき、それぞれ異なる強度を設定できます。
- `裸眼3D強調`は画面面Depthを境に手前と奥を逆方向へ動かし、顔の前後移動による近接ズーム、動的遮蔽、接地影、画面端の空間陰影を同期します。
- 設定表示中は人物／物体マスク、キャラ範囲、光源Rayを重ね、キャラ中心と光源を画像上でドラッグできます。
- 人物自動分離または任意マスクの輪郭で非破壊に切り抜き、境界ぼかし、Undo／Redoを利用できます。
- 正式な顔追跡確認には、HTTPSの公開版をiPhone Safariで開いてカメラを許可してください。
- 一般的な画面で行う1人向けの視点追従表現であり、左右の目へ別映像を送る裸眼ステレオ表示ではありません。

## 開発確認

```bash
python3 scripts/ci/web_regression_gate.py
python3 -m http.server 8080
```

`http://localhost:8080/` はデスクトップ確認用です。iPhoneからMacのLAN内HTTPへアクセスする方式ではSecure Contextにならず、カメラを利用できない場合があります。

AIごとの入口は `CLAUDE.md`、`AGENTS.md`、`GEMINI.md` を参照してください。

デモ画像の生成条件、プロンプト、ファイルハッシュは[`Docs/DEMO_ASSETS.md`](Docs/DEMO_ASSETS.md)に記録しています。
